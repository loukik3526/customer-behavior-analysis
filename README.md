# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using Python, Pandas, Microsoft SQL Server (MSSQL), and Power BI. It follows an end-to-end data analysis workflow, from cleaning raw CSV data to performing SQL-based analysis and building an interactive dashboard.

The project aims to uncover customer purchasing patterns, spending trends, product preferences, discount usage, and subscription behavior to support data-driven business decisions.

## 🎯 Project Objectives

- Analyze customer purchasing and spending patterns.
- Understand the relationship between discounts and customer spending.
- Identify popular products and highly rated items.
- Compare spending behavior between subscribers and non-subscribers.
- Segment customers based on their purchase history.
- Visualize key business insights using Power BI.

## 🛠️ Tools & Technologies

- **Python:** Data processing and analysis
- **Pandas:** Data cleaning and manipulation
- **CSV:** Dataset format
- **Microsoft SQL Server (MSSQL):** Advanced SQL analysis
- **Power BI:** Interactive dashboard and visualization
- **Jupyter Notebook:** Python analysis workflow
- **Microsoft PowerPoint:** Presentation of project findings
- **PDF:** Project report

## 🔄 Project Workflow

1. **Data Cleaning:** Imported the customer shopping dataset and cleaned the data using Python and Pandas.
2. **Data Analysis:** Explored the cleaned data to understand customer behavior and purchasing trends.
3. **SQL Analysis:** Used Microsoft SQL Server to answer business questions through SQL queries.
4. **Dashboard Development:** Created a Power BI dashboard to present key metrics and insights.
5. **Reporting:** Prepared a PowerPoint presentation and a PDF report to communicate the project and its findings.

## 📊 Business Questions

The analysis explores questions such as:

1. What is the total revenue generated by different customer groups?
2. How do discounts affect customer purchasing behavior?
3. Which products receive the highest average review ratings?
4. How does spending differ between Standard and Express shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which products have the highest percentage of discounted purchases?
7. How can customers be classified as New, Returning, or Loyal?
8. Which products are purchased most frequently in each category?
9. Are customers with more previous purchases more likely to subscribe?
10. How does revenue vary across different age groups?

## 🚀 How to Explore the Project

1. Download or clone this repository.
2. Open `Customer_Shopping_Behavior.ipynb` in Jupyter Notebook to review the Python analysis.
3. Open `customer_behavior_query.sql` in SQL Server Management Studio (SSMS) to explore the SQL queries.
4. Open the `.pbix` file in Power BI Desktop to explore the dashboard.
5. Review the PowerPoint presentation and PDF report for the project's findings.

*Note: You may need to configure the dataset path or database connection before running the notebook, SQL queries, or Power BI report.*
